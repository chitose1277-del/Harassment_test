# 判定の根拠
#
# 「事業主が職場における優越的な関係を背景とした言動に起因する問題に関して
#   雇用管理上講ずべき措置等についての指針」
#   （令和2年厚生労働省告示第5号。以下「パワハラ指針」）
#
# パワハラの3要素（3つすべてを満たすもの）
#   1 優越的な関係を背景とした言動であって
#   2 業務上必要かつ相当な範囲を超えたものにより
#   3 労働者の就業環境が害されるもの
#
# 代表的な言動の6類型
#   1 身体的な攻撃（暴行・傷害）
#   2 精神的な攻撃（脅迫・名誉棄損・侮辱・ひどい暴言）
#   3 人間関係からの切り離し（隔離・仲間外し・無視）
#   4 過大な要求（業務上明らかに不要なことや遂行不可能なことの強制・仕事の妨害）
#   5 過小な要求（業務上の合理性なく能力や経験とかけ離れた程度の低い仕事を
#     命じることや仕事を与えないこと）
#   6 個の侵害（私的なことに過度に立ち入ること）
#
# 指針は、6類型を限定列挙ではないとしています。また該当性は3要素を
# 総合的に見て判断するとしており、1つの発言だけで決まるものではありません。
# ------------------------------------------------------------
